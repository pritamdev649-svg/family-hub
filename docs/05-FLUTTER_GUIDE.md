## 1. Golden rules

1. **Design tokens only.** Never hard-code colours, font sizes, font weights, paddings, gaps, radii or durations in
   feature code. Use `AppSpacing`, `AppRadius`, `AppDurations`, `Theme.of(context).textTheme.*`,
   `Theme.of(context).colorScheme.*` and `context.semanticColors` (success / warning / sos / income / expense…).
   Gaps: `AppGap.md` (vertical) / `AppGap.hMd` (horizontal) — never `SizedBox(height: 12)`.
2. **DRY.** Before writing a widget, check `lib/core/widgets/` (§4). Formatting → `Fmt` (§5). Validation →
   `Validators`. JSON parsing → `lib/shared/json.dart`. Error → message → `context.showError(e)` / `ErrorView`.
   Enum → label → `*Labels` extensions. No copy-pasted helpers inside features.
3. **State = Riverpod 3.** Every screen handles **loading, error (with retry), empty and data** states through
   `AsyncValueView`. Mutations show a busy state on the triggering button (`AppButton(isLoading: …)`), disable
   double-submits, surface errors with `context.showError(e)`, and on success `ref.invalidate(...)` the affected
   providers (lists, dashboard) so every screen is consistent. Check `context.mounted` after every `await`.
4. **Localisation everywhere.** No user-visible string literals. Use `context.l10n.someKey` (see §6). Dates, times,
   numbers and money via `Fmt` (locale + family currency). Layouts must work RTL (Arabic): use
   `EdgeInsetsDirectional`, `AlignmentDirectional`, `start/end` — never `left/right`.
5. **Accessibility & low-end phones.** Min tap target 48dp, `Semantics` labels on icon-only buttons, respect the
   large-text setting (text scales up to 1.4× — no fixed-height text containers, use `Flexible`/`Wrap`),
   `cached_network_image` for network images, image uploads resized (maxWidth 1600, quality 80), lists use
   `ListView.builder`/`separated`, and pagination "load more" for long lists.
6. **Null-safety & robustness.** Models parse defensively (unknown enum → fallback value, missing field → null or
   sensible default, never throw on extra fields). Never `!` on server data.
7. **Permissions are enforced by the backend, mirrored by the UI.** Hide/disable actions the current member cannot
   perform (use `isAdminProvider`, `currentMemberProvider`) but always handle `FORBIDDEN` gracefully.

## 7. Networking, errors, mock backend

- `ApiClient` (`core/network/api_client.dart`): `Future<dynamic> get(String path, {Map<String, dynamic>? query})`,
  `post(path, {Object? body, Map<String, dynamic>? query})`, `patch(path, {Object? body})`, `put(path, {Object? body})`,
  `delete(path, {Object? body})` → returns the **unwrapped `data`**; `Future<Paged<T>> getPaged<T>(String path, T Function(Map<String, dynamic>) fromJson, {Map<String, dynamic>? query, int page = 1, int limit = 20})`.
  Throws only `ApiException`.
- `ApiException implements Exception { final String code; final String message; final int? statusCode; final Map<String, dynamic>? details; bool get isNetwork; bool get isUnauthorized; }` + `abstract final class ApiErrorCode { static const network='NETWORK_ERROR', timeout='TIMEOUT', unknown='UNKNOWN', ... every contract code }`.
- `localizedErrorMessage(Object error, AppLocalizations l10n)` in `core/l10n/error_messages.dart` maps codes → `error*` keys (fallback: server message, then `errorUnknown`).
- `Paged<T> { final List<T> items; final int page, limit, total; final bool hasMore; Paged.empty(); Paged<T> append(Paged<T> next); }`.
- Interceptors: `LocaleInterceptor` adds `Accept-Language`; `AuthInterceptor` adds `Authorization`, on `401 TOKEN_EXPIRED` performs **single-flight** refresh (`POST /auth/refresh` via a separate bare Dio), retries the original request once, on refresh failure clears tokens and emits `AuthEvents.sessionExpired`.
- `core/providers/core_providers.dart`: `sharedPreferencesProvider` (overridden in `main`), `tokenStorageProvider`, `localCacheProvider`, `authEventsProvider` (`class AuthEvents { Stream<void> get sessionExpired; void emitSessionExpired(); }`), `mockBackendProvider` (null when real API), `dioProvider`, `apiClientProvider`.
- **Mock backend** (`core/network/mock/`) — used when `AppConfig.useMockApi` (no `API_BASE_URL`). It implements the
  contract in memory so the app is fully usable without a server:
  - `mock_backend.dart`: `class MockBackend { final MockDb db; void on(String method, String pattern, MockHandler handler); Future<MockResponse> handle(RequestOptions o); }` — patterns like `/tasks/:id/complete`. `typedef MockHandler = FutureOr<MockResponse> Function(MockRequest req);` `class MockRequest { method, path, pathParams, query, body (Map<String,dynamic>), String? userId /*from 'Bearer mock-access.<userId>'*/, MockDb db; Map<String,dynamic> requireUser(); Map<String,dynamic> requireMember(); bool get isAdmin; }` · `class MockResponse { status, data, meta; MockResponse.ok(data); MockResponse.created(data); MockResponse.paged(List items, MockRequest req); }` · `class MockException implements Exception { status, code, message, details }` with helpers `MockException.notFound()`, `.forbidden()`, `.validation(Map details)`, `.conflict(code)`.
  - `mock_db.dart`: `class MockDb` with `Map<String, List<Map<String, dynamic>>> collections` and helpers
    `List<Map<String,dynamic>> col(String name)`, `String newId()` (24-hex), `String nowIso()`, `Map? findById(col, id)`, `insert`, `update`, `remove`. Collection names: `users families members refreshTokens otps devices tasks ledgerEntries goals notices sosAlerts emergencyCards`. Seed (core): demo family **"Sharma Family"** (IN, INR, Asia/Kolkata, invite code `DEMO2345`), members Amit (admin, Head of Family, 1985), Priya (admin, Finance Head, 1987), Aarav (member, 2010), Anaya (member, 2016, no account), Kamla (member, 1952, Advisor, no account); users `demo@familyhub.app` / `demo1234` (Amit, verified) and `priya@familyhub.app` / `demo1234`. OTP in mock mode is always **`123456`**. Feature mock files seed their own collections via `db.seedOnce('<collection>', () => [...])`.
  - `mock_interceptor.dart`: wraps responses in the envelope, simulates 250–600 ms latency, converts `MockException` to the error envelope.
  - `mock_registry.dart`: `void registerAllMocks(MockBackend b)` calls `registerAuthMocks, registerMeMocks, registerFamilyMocks, registerTaskMocks, registerLedgerMocks, registerNoticeMocks, registerEmergencyCardMocks, registerSosMocks, registerDashboardMocks, registerUploadMocks` imported from `lib/features/<feature>/data/<feature>_mock_handlers.dart` (auth → `auth`, me+uploads → `settings`, family → `family`, tasks → `tasks`, ledger+goals → `ledger`, notices → `notices`, emergency cards → `emergency_card`, sos → `sos`, dashboard → `dashboard`).

## 10. Cross-feature public API (import these, don't duplicate)

**Data-change bus (decouples features):** `lib/shared/providers/data_refresh.dart` defines
`enum DataScope { family, members, tasks, ledger, goals, notices, sos, emergencyCards }`,
`final dataRefreshProvider = NotifierProvider<DataRefresh, Map<DataScope, int>>` and helpers
`void markChanged(Ref ref, Set<DataScope> scopes)` / `extension on WidgetRef { void markChanged(Set<DataScope> scopes) }`.
After **every successful mutation** a feature calls `markChanged({...})`. Every data provider watches the scopes it
depends on: `ref.watch(dataRefreshProvider.select((m) => m[DataScope.tasks]))`. The dashboard watches all scopes.
Never import another feature just to invalidate its providers.

## 11. Services (`lib/core/services/`)

- `PushNotificationService` (`pushNotificationServiceProvider`): `Future<void> init()`, `Stream<String> get routeTaps` (route strings from notification taps incl. cold start), `Future<void> registerDevice()` (FCM token → `POST /me/devices`, also on token refresh), `Future<void> unregisterDevice()`; no-op when Firebase is not configured. Android channels `sos_alerts` (max importance) and `general`. Foreground messages are shown with `flutter_local_notifications` on Android; iOS uses presentation options.
- `CloudinaryService` (`cloudinaryServiceProvider`): `Future<String> uploadImage(XFile file, {required UploadFolder folder, void Function(double progress)? onProgress})` — signed upload via `POST /uploads/signature` (default) or unsigned preset if configured; in mock mode without Cloudinary config returns the local file path. `enum UploadFolder { avatars, notices }`.
- `LocationService` (`locationServiceProvider`): `Future<LocationPermissionState> ensurePermission({bool background=false})`, `Future<GeoFix?> currentFix()`, `Stream<GeoFix> track({required String notificationTitle, required String notificationText})` (Android foreground service notification + iOS background indicator), `Future<bool> openSettings()`. `enum LocationPermissionState { granted, denied, deniedForever, serviceDisabled }`, `class GeoFix { lat, lng, accuracy, at }`.
